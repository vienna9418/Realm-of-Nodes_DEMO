
# Core Logistics & Synthesis Hub | 核心物流与合成中心

A high-fidelity automation and resource management interface designed for complex industrial simulations and strategic planning. This application features a real-time node-based logistics canvas and a dynamic resource synthesis encyclopedia.

一款专为复杂工业模拟和战略规划设计的高保真自动化与资源管理界面。该应用集成了实时节点式物流画布和动态资源合成百科。

---

## 🌐 English Introduction

### Overview
The **Core Logistics & Synthesis Hub** provides a sophisticated platform for managing planetary-scale industrial operations. Whether you are building complex supply chains or researching forbidden technologies, the interface offers the precision and aesthetic feedback required for modern industrial commanders.

### Key Features
- **Node-Based Logistics Canvas**: 
  - Place extractors, processors, and assemblers.
  - Establish connections with real-time "flow" visual effects.
  - Automated propagation logic: child nodes activate only when receiving resources from active parents.
  - Right-click management for rapid deconstruction and path clearing.
- **Dynamic Resource Encyclopedia**:
  - Browse resources across four tiers: Basic, Intermediate, Advanced, and Mythic.
  - Interactive synthesis flow diagrams showing exact ingredient requirements.
  - Real-time production simulation with visual progress tracking.
- **Strategic Monitoring**:
  - Live task panel tracking system throughput and node status.
  - Power grid monitoring and resource inventory integration.
- **Immersive UI/UX**:
  - Glassmorphism design language with high-performance animations.
  - Responsive layout with deep-space dark mode aesthetics.

## 🏮 中文介绍

### 项目概览
**核心物流与合成中心** 是管理星球级工业运作的先进平台。无论您是在构建复杂的供应链，还是在研究禁断科技，本界面都能为现代工业指挥官提供所需的精确控制和极致视觉反馈。

### 核心功能
- **节点式物流画布**：
  - 自由放置提取器、加工厂、组装机等多种工业设施。
  - 建立具有实时“流光”特效的传送连接。
  - 自动化传导逻辑：下级节点仅在收到活跃上级提供的资源时才会启动。
  - 右键管理功能：快速拆除建筑或清除物流路径。
- **动态资源百科**：
  - 浏览从基础、复合到高阶、神话级别的全量资源。
  - 交互式合成流向图，直观展示原材料需求及配方逻辑。
  - 实时生产模拟，配备动态进度追踪。
- **战略监控系统**：
  - 实时任务面板追踪系统总吞吐量及各节点运行状态。
  - 集成电网监控与全球资源库存管理。
- **沉浸式 UI/UX 设计**：
  - 采用玻璃拟态设计语言，配合高性能流畅动画。
  - 响应式布局，深空暗黑风格美学，极具未来感。

## 🛠 Technical Highlights | 技术亮点

- **Engine**: React 19 + TypeScript
- **Styling**: Tailwind CSS (Custom extended theme)
- **Visuals**: SVG Motion Paths + Material Symbols
- **State**: Complex recursive node state propagation logic
- **Performance**: Optimized render cycles for large-scale node networks

## 🚀 How to Use | 使用指南

1. **Build (构建)**: Select components from the left sidebar and click the grid to place them.
2. **Connect (连接)**: Click an output port (right) then an input port (left) to form a logistics belt.
3. **Manage (管理)**: Use the Task Panel on the top right to monitor efficiency. Right-click any object to delete it.
4. **Synthesize (合成)**: Switch to Encyclopedia view to research recipes and simulate synthesis.

1. **构建**：从左侧工具栏选择组件，点击网格区域进行放置。
2. **连接**：点击输出端口（右侧）再点击输入端口（左侧）以建立物流传送带。
3. **管理**：使用右上角的任务面板监控效率。右键点击任何物体即可将其拆除。
4. **合成**：切换至百科视图研究配方并模拟生产循环。
